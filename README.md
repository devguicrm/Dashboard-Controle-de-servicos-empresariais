# ServiceControl — Dashboard de Ordens de Serviço

Dashboard front-end desenvolvido para controle simples de ordens de serviço, ideal para empresas de manutenção, reformas, assistência técnica ou prestadores de serviços.

## Funcionalidades

- Cadastro de ordens de serviço
- Edição e exclusão de registros
- Filtro por status
- Busca por cliente, serviço ou descrição
- Cards com indicadores principais
- Relatório de taxa de conclusão
- Resumo por tipo de serviço
- Tema claro/escuro
- Dados salvos no LocalStorage
- Layout responsivo

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome

## Possíveis melhorias futuras

- Integração com backend
- Login de usuário
- Exportação para PDF ou Excel
- Integração com WhatsApp
- Dashboard com gráficos reais

## Descrição para portfólio

Dashboard responsivo para gerenciamento de ordens de serviço, com cadastro, edição, exclusão, filtros, indicadores e persistência de dados no navegador usando LocalStorage.
